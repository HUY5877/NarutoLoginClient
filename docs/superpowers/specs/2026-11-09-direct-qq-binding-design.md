# QQ 直接创建用户并绑定

用户已确认：在 `test` 分支修改 `bind_qq`，可信后台只传当前消息发送者的数字 QQ；没有绑定时自动创建可用的普通网站用户并建立关联，有绑定时返回原 `userId`，不再要求网页登录或确认链接。QQ 端启用此工具。

## 实现选择

在现有数字 QQ 绑定服务增加原子的 `bind(qq)`，沿用既有事务和写锁，直接返回 `{ qq, userId }`。创建用户与插入关联在同一事务内完成；并发和重试只产生一个用户。复用有效旧绑定，已停用用户保持停用并返回错误。新账号非管理员、显式可用，使用不会泄露给调用方的随机密码和独立用户名，不按用户名猜测或接管已有账号。

保留原有网站确认接口与旧链接兼容逻辑，MCP 不再生成新链接。共享 Bearer 认证保持。QQ 启动配置只开放 `bind_qq`，其他此前关闭的业务工具保持关闭；现有真实发送者核验和审批规则保持。同步业务文档和部署技能，避免继续要求网页登录。

## 验证

覆盖首次创建、重复复用、并发同 QQ、不同 QQ、旧绑定复用、停用账号、事务回滚、非法参数和 Bearer 拒绝。通过真实 HTTP MCP 与隔离数据库验证无 Cookie 的直接绑定返回。执行类型检查和构建；提交推送到 `origin/test` 后核对测试站部署，再验证 QQ 专用配置发现工具。不要为验证使用他人的 QQ，也不发送真实 QQ 消息。
